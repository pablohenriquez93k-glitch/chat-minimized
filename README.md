# Chat Minimized

Planetary Annihilation: TITANS client mod. The PA Chat community chat starts minimized in the main menu; click its header to open it as usual.

Settings > CHAT: on startup (minimized / open / remember last state; channels unseen for 30 days are forgotten, up to 50 kept), open window width and height as a percentage of the screen (minimum = PA Chat's own 420x240 px, maximum 71.15% x 71.11%), window opacity, hide the chat completely.

Requires PA Chat (installed automatically by the game). Translations are machine-generated and may contain errors.

Install: Community Mods (in game). Feedback: https://github.com/pablohenriquez93k-glitch/chat-minimized/discussions/1
