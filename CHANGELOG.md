# Changelog

## 1.1.0 (2026-10-08)

- Settings are applied right after SAVE in the CHAT tab; the chat no longer re-reads settings every 2 seconds.
- Waits up to 60 seconds for PA Chat to load (was 10), and logs a console line if it never appears.
- PA Chat's own maximum window height is restored when the chosen height no longer needs it.
- "Remember last state" keeps channels seen in the last 30 days (at most 50); older private channels are removed.
- Known limit: settings saved from the in-match Settings menu apply the next time the main menu loads.
